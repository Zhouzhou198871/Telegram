API 接口文档

API 基础地址： https://shop.lynli.me

鉴权方式： HTTP Bearer Token，所有接口均要求有效 API Key，且账户余额至少 ¥500。

GET
/api/v1/account
读取账户邮箱、昵称、余额与最低余额要求。
GET
/api/v1/products
查询全部可售商品，返回商品详情、价格、库存、图标、价格验证状态。
GET
/api/v1/products/{product_id}
查询单个商品详情与实时库存。
POST
/api/v1/orders
创建商品购买订单。请求头必须携带 Idempotency-Key，避免网络重试导致重复下单。
GET
/api/v1/orders
读取当前 API 账户最近 100 笔商品订单。

1. 查询商品

curl "https://shop.lynli.me/api/v1/products" \
  -H "Authorization: Bearer YOUR_API_KEY"

2. 查询单个商品

curl "https://shop.lynli.me/api/v1/products/PRODUCT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"

3. 提交购买订单

curl -X POST "https://shop.lynli.me/api/v1/orders" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: YOUR_UNIQUE_REQUEST_ID" \
  -d '{"product_id":"PRODUCT_ID"}'

4. 查询订单记录

curl "https://shop.lynli.me/api/v1/orders" \
  -H "Authorization: Bearer YOUR_API_KEY"
响应字段与错误码

商品字段： product_id、name、category、icon、icon_url、price_cny、price_usdt、stock、currency、price_verified、purchasable。

订单状态： reserved（已扣款待处理）、pending（处理中）、delivered（交付成功）、refunded（失败已退款）。

常见 HTTP 状态： 200/201 成功；202 订单处理中；400 参数错误；401 密钥缺失或无效；403 余额不足 ¥500 或无 API 资格；402 商品金额余额不足；404 商品不存在；409 商品下架、库存不足、价格快照过期或幂等键冲突；503 商品价格无效或上游配置异常。

商品价格与库存会在下单时再次校验；目录数据超过 180 秒未更新时，非本地库存商品不可购买。失败订单由现有购买流程退款。
